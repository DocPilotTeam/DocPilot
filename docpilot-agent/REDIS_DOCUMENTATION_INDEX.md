## 📋 What You Need to Provide (Always)

```
3 VALUES FROM YOUR REDIS PROVIDER:

1. Redis Host/Endpoint
   Example: redis-12345.c123.us-east-1-2.ec2.cloud.redis.io

2. Redis Port
   Example: 6379

3. Redis Password/Auth Token
   Example: abc123def456ghi789
```
